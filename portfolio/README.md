
# Portfolio de Vicent

## Descripción

Este proyecto es mi portfolio personal para mostrar lo que estoy
aprendiendo en Desarrollo de Aplicaciones Multiplataforma.

Contiene una página de presentación y otra donde explico mi entorno
de trabajo y cómo funciona la navegación por Internet.

## Tecnologías y herramientas

- HTML5
- Visual Studio Code
- Emmet
- Live Server
- Git
- GitHub

## Archivos

- `index.html`: portada del portfolio.
- `entorno.html`: explicación de mi entorno de trabajo.
- `img/`: carpeta para guardar imágenes.
