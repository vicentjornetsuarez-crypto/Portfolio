Mi entorno de trabajo

Qué ocurre cuando escribo una URL

Cuando escribo una URL en el navegador, este busca la dirección del servidor mediante el DNS. Después se conecta al servidor y le solicita la página. El servidor envía los archivos y el navegador interpreta el HTML para mostrar la web.

  1. Escribo la dirección de la página.
  2. El navegador busca la dirección IP mediante el DNS.
  3. El navegador solicita la página al servidor.
  4. El servidor responde enviando los archivos.
  5. El navegador interpreta el código y muestra la página.

Mis herramientas

  • Visual Studio Code: lo utilizo para escribir y editar el código.
  • Emmet: me permite crear la estructura HTML escribiendo ! y pulsando Tab.
  • Live Server: abre la página en el navegador y la actualiza cuando guardo cambios.
  • DevTools: me permite inspeccionar el HTML desde el navegador.
  • Git: sirve para guardar versiones de los cambios del proyecto.
  • GitHub: permite guardar el repositorio en Internet y compartirlo.
